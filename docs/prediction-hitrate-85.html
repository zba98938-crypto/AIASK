预测命中率 85% 方案

在模拟盘中把「股票走势方向预测命中率 ≥85%」做成可测量、可校准、可审计、不可绕过的工程目标。本方案逐项列出需求、现状证据、架构、流程、数据关系、代码落点、周期与验收标准。

01实际需求：把 85% 变成可判定的契约

需求原文：在模拟盘模拟交易时，预测股票走势达到 85% 以上的命中率。本文不改写这个目标，而是把它拆成四条可交付契约——因为「85% 命中」只有在口径、样本、计算方式全部冻结后才是一个可验证的主张。

四条契约

编号契约内容当前状态
R1可测量模拟盘必须给出逐预测的「预测 → 结算」判分：按 horizon 净收益方向、扣双边成本、T+1、缺数据记 null 并带原因码。不可用 1,572 条 outcome 中 88% 为 null，0 行 score_status=ok
R2可达成必须有具频率含义的概率来源（校准后的 confidence），而不是规则公式常数。缺失 8,932 条预测中 3,519 条 confidence 恰为 0.675807；calibrated_confidence 仅 1/231 行有值
R3可选择只在高置信时出手（选择性交易），低置信记录 abstain；否则全量命中率天花板由市场决定。缺失 paper bridge 发单不读任何 confidence
R4可审计判据预注册、样本独立归并、记录与 candidate hash 绑定、任一输入变更即失效、不达标不降门槛。已具备骨架 门禁开关被硬编码关闭（仅诊断）；证书机制 v1 已实现

项定义（冻结，改动需升 gate 版本）

04端到端流程：一个预测从生成到结算

从 T 日收盘生成预测，到 T+k 日结算判分，再到记分卡与门禁决策。每一步都写明数据、判定条件与失败路径（fail-closed）。

图 4 · 单预测生命周期。关键约束：abstain 必须入库（否则选择性偏差不可见）；缺 bar 一律 null + 原因码；判分幂等，重跑不新增。

每日调度时序

  1. 07:30 纸面周期（现有 scheduler）：加载 incubating 策略 → 对每个目标标的独立取 120 根已收盘 bar → 生成信号。
  2. 开工前校准回填（WP-B）：对当日所有预测套用最新封存模型，写 calibrated_confidence；无模型 → 保持 null。
  3. 出手判定（WP-C）：calibrated_confidence ≥ 0.85 才调用 _place_paper_order；否则写 abstain 动作记录，不发单。
  4. 成交与净值（现有）：下一交易时段开盘价成交，T+1 约束、整手、费用入账；收盘后写 NAV 快照。
  5. 到期判分（WP-A）：扫描 horizon 已到的预测，按 T+1..T+k 净收益写 outcome。
  6. 记分卡（WP-D）：按 (stock_code, prediction_as_of) 归并独立样本，输出 n / hit_rate / Wilson LCB / Brier / regime 覆盖 / abstain 率 / 距 n=200 差值。

图 5 · 数据关系（ER）。灰色为现有表，青色为新增表/列。校准模型通过 model_hash 回填预测；执行动作表把「出手 / 不出手」都变成可审计样本；证书引用记分卡，任何输入变化都会使证书失效。

ALTER TABLE strategy_trade_predictions ADD COLUMN IF NOT EXISTS calibrated_confidence REAL;
ALTER TABLE strategy_trade_predictions ADD COLUMN IF NOT EXISTS calibration_model_hash TEXT;

-- 2) 校准模型注册表
CREATE TABLE IF NOT EXISTS calibration_models (
    model_hash       TEXT PRIMARY KEY,
    strategy_family  TEXT NOT NULL,
    method           TEXT NOT NULL,          -- platt | isotonic
    feature_version  TEXT NOT NULL,
    fit_start        TEXT NOT NULL,
    fit_end          TEXT NOT NULL,
    n_train          INTEGER NOT NULL,
    n_holdout        INTEGER NOT NULL,
    brier_holdout    REAL,
    brier_baseline   REAL NOT NULL,          -- 0.25（p=0.5 常数基线的 Brier）
    status           TEXT NOT NULL,          -- active | rejected | retired
    created_at       TEXT DEFAULT CURRENT_TIMESTAMP
);

-- 3) 执行动作表（ordered 与 abstained 都是样本）
CREATE TABLE IF NOT EXISTS prediction_executions (
    id                     TEXT PRIMARY KEY,
    prediction_id          TEXT NOT NULL,
    action                 TEXT NOT NULL CHECK (action IN ('ordered','abstained')),
    reason                 TEXT,
    calibrated_confidence  REAL,
    calibration_model_hash TEXT,
    paper_order_id         TEXT,
    created_at             TEXT DEFAULT CURRENT_TIMESTAMP
);
CREATE INDEX IF NOT EXISTS idx_prediction_executions_prediction
    ON prediction_executions(prediction_id);

WP-B · 校准层

新增2 周

目标：把「规则 confidence」映射成有频率含义的 calibrated_confidence，并用封存 holdout 证明映射有效。

接口：

# aiask_quant_core/calibration.py
def fit_platt(features: np.ndarray, hits: np.ndarray, *,
              fit_end: str) -> dict        # {"model":..., "model_hash":..., "brier":...}
def fit_isotonic(features, hits, *, fit_end: str) -> dict
def brier_score(probs, hits) -> float
def reliability_curve(probs, hits, bins: int = 10) -> list[dict]

class CalibrationService:
    async def fit_family(self, db, family: str) -> dict
    async def apply(self, db, predictions: list[dict]) -> list[dict]

规则：按时间切分（fit_end 之前训练、之后封存）；holdout Brier 必须优于 0.5 常数基线（0.25）才允许 status=active；样本不足（<100 独立块）拒绝拟合；模型注册进 calibration_models，预测回填 calibrated_confidence 与 calibration_model_hash；无 active 模型时保持 null。

特征：原始 confidence、horizon、strategy_family、市场状态、信号强度分位——全部在预测时刻可得，禁止使用目标日 bar。

测试：packages/aiask-quant-core/tests/test_calibration.py（已知概率源恢复；跨封存点拒绝；样本不足拒绝；Brier 基线门禁；模型哈希失效）

里程碑

  • M0（工程完成）：三包全绿；记分卡可运行；证书可生成且可失效。
  • M1（n=50）：报告首批实测命中率与 LCB；确认数据缺口只剩真实停牌。
  • M2（n=100）：校准曲线稳定性检查；regime 覆盖是否达到 2 个。
  • M3（n=200）：正式判定 85% 判据；通过则推进状态，不通过则报告差距与下一里程碑。
  • M4（决策门）：决定是否投入 WP-E；不满足条件时明确记录「不可达」结论。

10风险与诚实声明

统计风险

多重检验：8,932 个策略里挑高命中率，PBO/DSR 失败率极高；因此所有判据必须绑定同一候选身份并做多重检验校正。重叠窗口与同标的多策略会制造虚假样本。

数据风险

88% null 主要来自缺分钟 bar 与目标日未到；补数据是独立工作包，不能用估算填充。判分日由数据推导，不用墙钟。

样本饥饿

选择性交易下手数骤降；n=200 独立判分可能需要数月。期间「0 交易」是正常状态，不是故障。

高胜率陷阱

高胜率常伴随烂盈亏比；因此命中率必须与 PF≥1.5、净收益 LCB>0 并行判定，单看命中率会被骗。

诚实声明：本方案不承诺 85% 一定可达。它承诺的是：如果证据达到 85%，系统会以不可绕过的方式判定并记录；如果达不到，系统会给出实测值、置信区间、缺口原因与下一次重评所需的数据里程碑。任何声称「保证 85%」的系统都在隐瞒分布。

本方案不启用真实资金交易，不接入券商，不构成任何收益承诺或实盘授权。
